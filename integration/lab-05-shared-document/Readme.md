# LAB 5 — End-to-End Collaboration Workflow

## Objective

In this lab, you will use Outlook, Microsoft Teams, OneDrive, SharePoint, and Microsoft 365 collaboration features together in a single workflow.

You will learn how to:

* Receive a request through Outlook.
* Store a document in OneDrive.
* Share a document with other people.
* Collaborate on the same document.
* Use Microsoft Teams to coordinate the work.
* Schedule a Teams meeting from Outlook.
* Access the shared document from Teams.
* Review the final document.

---

## Scenario

You receive an email asking your team to review a project document before a meeting.

You need to:

1. Store the document in Microsoft 365.
2. Share it with your colleagues.
3. Collaborate on the document.
4. Coordinate the work using Teams.
5. Schedule a meeting to discuss the final version.

You will complete the entire process without sending copies of the document as email attachments.

---

# Step 1 — Open Outlook

1. Open Outlook.

2. Go to **Mail**.

3. Open the email provided by your instructor.

The email contains a project document that needs to be reviewed.

---

# Step 2 — Save the document to OneDrive

1. Open the attachment.

2. Select **Save** or **Save to OneDrive**, depending on the options displayed.

3. Save the document in your OneDrive.

4. Give the document the following name:

```text
Project_Review.xlsx
```

5. Confirm that the document is stored in OneDrive.

---

# Step 3 — Share the document

1. Open OneDrive.

2. Locate:

```text
Project_Review.xlsx
```

3. Select the file.

4. Select **Share**.

5. Add the participants provided by your instructor.

6. Make sure they have permission to edit the document.

7. Add the following message:

```text
Please review the project document before our meeting.
```

8. Select **Send**.

---

# Step 4 — Open Microsoft Teams

1. Open Microsoft Teams.

2. Select **Teams** from the navigation menu.

3. Open the team provided by your instructor.

4. Open the channel provided by your instructor.

---

# Step 5 — Share the document in Teams

1. Open the channel's **Files** or **Shared** section.

2. Select **Upload** or **Add**.

3. If your instructor has provided a shared document for the team, locate it there.

4. Otherwise, use the option to share the OneDrive file according to the instructions provided by your instructor.

5. Confirm that the document is available to the team.

---

# Step 6 — Work on the document together

1. Open:

```text
Project_Review.xlsx
```

2. Ask another participant to open the same document.

3. Both participants should edit the document at the same time.

### Participant A

Add:

```text
Project status: In progress
```

### Participant B

Add:

```text
Review required before Friday
```

4. Verify that both changes appear in the same document.

Do not download or create a separate copy.

---

# Step 7 — Add a comment

### Participant A

1. Select a cell or section that requires review.

2. Add a comment.

3. Enter:

```text
Can you verify this information?
```

4. Mention Participant B using `@`.

---

# Step 8 — Respond to the comment

### Participant B

1. Open the comment.

2. Select **Reply**.

3. Enter:

```text
Reviewed. The information is correct.
```

4. Resolve the comment when the review is complete.

---

# Step 9 — Schedule the review meeting

Now you will schedule a Teams meeting to discuss the document.

1. Open Outlook.

2. Select **Calendar**.

3. Select **New event**.

4. Enter the following title:

```text
Project Review Meeting
```

5. Add the participants.

6. Select the **Teams meeting** option.

7. Add the following agenda:

```text
Agenda

1. Project status
2. Document review
3. Open items
4. Next steps
```

8. Select **Send**.

---

# Step 10 — Open the meeting in Teams

1. Open Microsoft Teams.

2. Select **Calendar**.

3. Find:

```text
Project Review Meeting
```

4. Open the meeting.

5. Review the participants and meeting information.

---

# Step 11 — Review the final document

Before the meeting:

1. Open the document from Teams.

2. Review the latest changes.

3. Check the comments.

4. Make sure the required information has been updated.

5. Open **Version History** if available.

6. Confirm that the latest version contains the team's changes.

---

# Step 12 — Join the meeting

At the scheduled time:

1. Open the meeting from Teams or Outlook.

2. Select **Join**.

3. Check your microphone and camera settings.

4. Join the meeting.

The team can now discuss the document using the latest shared version.

---

# Complete workflow

You have now completed the entire Microsoft 365 collaboration workflow:

```text
OUTLOOK

   ▼

   ▼

   │

   ├── Comments
   ├── @Mentions
   └── Version History
   │
   ▼
OUTLOOK
   │
   │ Schedule meeting
   ▼
TEAMS
   │
   │ Review final document
   ▼
PROJECT REVIEW
```

## Lab completed

You have successfully used Outlook, OneDrive, SharePoint/Teams, and Microsoft 365 collaboration features together.

You completed the workflow without repeatedly downloading, copying, and sending different versions of the same document.
