# LAB 4 — Collaborate on a File in Microsoft 365

## Objective

In this lab, you will learn how to collaborate with another person on the same Microsoft 365 document.

You will learn how to:

* Open a shared document.
* Edit a document at the same time as another person.
* See changes made by another user.
* Add comments.
* Mention another user using `@`.
* Reply to comments.
* Resolve comments.
* View the version history.

---

## Scenario

You and a colleague are working on the same project document.

Instead of sending different copies of the document back and forth by email, you will both work on the **same file at the same time**.

For this exercise, work with another participant.

* **Participant A:** you
* **Participant B:** your partner

---

# Step 1 — Open the shared file

1. Open Microsoft Teams.

2. Open the team and channel provided by your instructor.

3. Open the **Files** or **Shared** section.

4. Locate the document provided for this exercise.

5. Open the document.

The document will open in Microsoft Word for the web.

---

# Step 2 — Make sure both participants have the document open

Participant A and Participant B should both open the **same document**.

Do not download the document.

Do not create a copy.

Both participants must work with the original shared file.

---

# Step 3 — Edit the document

### Participant A

1. Locate the section assigned by the instructor.

2. Add the following text:

```text
Project status: In progress
```

3. Do not close the document.

### Participant B

1. Locate a different section of the document.

2. Add the following text:

```text
Next review: Friday
```

3. Do not close the document.

---

# Step 4 — Observe co-authoring

Look at the document while both participants are working.

You should be able to see that another person is also working on the document.

Changes made by one participant become available to the other participant.

There is no need to send the document by email.

Both participants are working on the **same file**.

---

# Step 5 — Add a comment

### Participant A

1. Select a sentence or piece of text in the document.

2. Select **New comment**.

3. Enter:

```text
Please review this section.
```

4. Post the comment.

---

# Step 6 — Mention another participant

1. Create another comment or edit the existing comment.

2. Type `@`.

3. Start typing the name of Participant B.

4. Select Participant B from the list.

5. Complete the comment:

```text
@Participant B, please review this section.
```

6. Post the comment.

The `@` mention helps identify the person who needs to review the comment.

---

# Step 7 — Reply to a comment

### Participant B

1. Locate the comment created by Participant A.

2. Select **Reply**.

3. Enter:

```text
Reviewed. I will update this section.
```

4. Post the reply.

The two participants can now have a conversation directly within the document.

---

# Step 8 — Make the requested change

### Participant B

1. Locate the section mentioned in the comment.

2. Make the requested change.

3. Save the document if required.

### Participant A

1. Verify that the change is visible.

2. Open the comment.

3. Select **Resolve** when the issue has been addressed.

The comment will no longer appear as an active comment.

---

# Step 9 — Open Version History

Now you will look at previous versions of the document.

1. In Word for the web, locate **Version History**.

2. Open it.

3. Review the versions that are available.

4. Select an earlier version.

5. Review the changes made to the document.

Do not restore a previous version unless your instructor asks you to do so.

---

# Step 10 — Continue working on the same document

Make one final change to the document.

For example:

```text
Project review completed.
```

Both participants should verify that the change is visible.

---

## Key concept

Traditional workflow:

```text
Person A
   │
   ▼
File.docx
   │
   └── Email attachment ──► Person B
                              │
                              ▼
                         File - Copy.docx
                              │
                              └──► Email back
```

Collaborative workflow:

```text
              ┌──► Person A
              │
Shared File ──┤
              │
              └──► Person B
```

Both participants work with the **same file**.

Changes, comments, and versions are managed within Microsoft 365.

---

## Lab completed

You have successfully:

* Opened a shared Microsoft 365 document.
* Edited the document simultaneously with another user.
* Observed real-time changes.
* Added a comment.
* Mentioned another user.
* Replied to a comment.
* Resolved a comment.
* Viewed the document's version history.
