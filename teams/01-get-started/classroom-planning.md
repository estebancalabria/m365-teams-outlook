# Classroom Guide — Get Started with Microsoft Teams

> **Objetivo:** guía rápida para el instructor.
> **Uso:** mantener este documento abierto en el segundo monitor y seguir la secuencia durante la demostración.

---

## 1. Introduction

### DECIR

> Welcome to Get Started with Microsoft Teams.
>
> Today we're going to focus on the basics you need to feel comfortable using Teams in your day-to-day work.
>
> We'll look at how to navigate Teams, send messages, collaborate using teams and channels, create and join meetings, make calls, and find your files.

### MOSTRAR

* Teams main window.
* Point out the overall layout.
* No need to explain every option yet.

### MENSAJE CLAVE

# 23. Screen Sharing

### MOSTRAR

Click **Share**.

Explain:

### Screen/Desktop

> Sharing your entire screen allows you to switch between different windows while presenting.

### Window

> Sharing a specific window limits the presentation to that application or window.

### IMPORTANT

> If you share a specific window and then minimize it, participants won't see the other applications you open.

### MENSAJE CLAVE

**Choose Screen when you need to switch between applications. Choose Window when you want to restrict what participants can see.**

# 31. Chat Files vs Channel Files

### MOSTRAR

Explain the distinction.

### DECIR

> There's an important difference between files shared in a channel and files shared in a chat.

### CHANNEL

> Files shared in a channel belong to that team's SharePoint location.

### CHAT

> Files shared in a one-to-one or group chat are stored in OneDrive.

### MOSTRAR

If possible:

Open OneDrive → **Microsoft Teams Chat Files**

### DECIR

> This folder contains files that I have shared through Teams chats.

### IMPORTANT

> If someone shares a file with me through chat, I need to go back to that conversation to find it.
