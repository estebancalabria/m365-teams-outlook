# Get Started with Microsoft Outlook

## Introduction

This training introduces the **new Outlook for Windows**, focusing on the main tools for managing email, organizing the inbox, working with the calendar, and managing contacts.

The content is grounded in the official Microsoft Learn **Discover new Outlook for Windows** learning path.

## Objectives

* Navigate and customize the new Outlook experience.
* Compose, send, schedule, and delay email.
* Organize and search the inbox.
* Create and manage calendar events.
* Share and delegate calendar access.
* Manage tasks with Microsoft To Do.
* Manage contacts and use People cards and the People hub.
* Use selected Copilot capabilities in Outlook.
